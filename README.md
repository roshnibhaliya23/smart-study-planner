
# Smart Study Planner

A responsive study planning web application built with HTML,
CSS and JavaScript. It helps students organize study tasks,
track deadlines and monitor their progress.

## Features

- Add study tasks with subjects and deadlines
- Edit, complete and delete tasks
- Filter all, pending, completed and overdue tasks
- Highlight overdue tasks
- Track task completion with a progress bar
- Display total, completed and pending task statistics
- Save tasks using browser localStorage
- Responsive layout for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional packages are required.

## How Data Is Stored

Tasks are stored locally in the browser using localStorage.
Data is not synced across devices or browser profiles.
